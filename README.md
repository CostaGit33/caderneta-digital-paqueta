Telas: início, cadastro, login, home, leitura NFC/QR simulada, caderneta, recompensas, lojas, perfil, confirmação, offline e painel administrativo.\n\nCódigos de teste: JEQUIE-123, JEQUIE-456, JEQUIE-789. Use HTTPS ou localhost para testar instalação PWA.\n\nLimitações: front-end demonstrativo; dados locais, sem sincronização, backend, autenticação real, NFC real ou antifraude. Métricas e lojas são ilustrativas. Não inserir dados pessoais reais. Revisão de privacidade, regulamento e aprovação empresarial são necessárias antes do lançamento.
